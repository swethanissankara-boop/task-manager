## Working agreement

- Every task is a GitHub Issue assigned to one person.
- Nobody pushes to `main`. Work on a branch and open a Pull Request.
- Reviews within one working day. At least one approval, and tests must pass.
- Questions about someone else's area: comment on the Issue or PR, or message them.
